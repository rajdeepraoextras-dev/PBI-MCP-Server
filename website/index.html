MCP servers for Power BI Projects

Talk to your Power BI project.

Ask Claude to build pages, write DAX, add security roles or restyle a report. pbi-mcp edits the files Power BI Desktop already uses, shows you the diff first, and undoes it on request.

Nothing changes without a preview.

Write tools can run as a dry run and return the exact diff. Real writes keep byte-exact copies of what they replaced, so one call puts everything back.

diffDry run
Preview any write as a unified diff. Nothing touches the disk.

      
undoJournal
Undo one write, several, or a whole transaction.

    Where it fits.
    
    
    There is an official Microsoft server too. They do different jobs, so pick the one that matches the task.
    
    
    
      
    
        pbi-mcp
        
    Works on the files
    
        
    Reads and writes the .pbip files on disk. Covers the semantic model and the report layer, so it can build pages and visuals. Every write can be previewed and undone, and lands in Git like any other file change.
    
      
    
      
    
        Microsoft Power BI Authoring MCP
        
    Works on a live model
    
        
    Edits semantic models through the engine, in Power BI Desktop and in Fabric workspaces. Its documentation says it does not change report pages. Reach for it when you need to change a model that is running.
    
        
    Read Microsoft's documentation
    
      
    
    
    
    
    Using one at a time keeps the assistant's tool list short. Two overlapping sets cost context and make it harder to choose the right tool.
